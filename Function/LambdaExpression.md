## 람다 표현식과 클로저 객체

### 1. 람다 표현식이란?

람다 표현식(lambda expression)은 C++11에서 도입된 기능으로, 필요한 위치에서 함수 객체를 간결하게 만들 수 있는 표현식이다.

람다 표현식을 평가하면 클로저 객체(closure object)라는 함수 객체가 생성된다. 클로저 객체는 함수 호출 연산자 `()`를 지원하므로 일반 함수처럼 호출할 수 있다.

람다 표현식은 다음과 같은 경우에 유용하다.

* 짧은 동작을 필요한 위치에서 바로 정의할 때
* 정렬이나 탐색 알고리즘에 비교·판정 동작을 전달할 때
* 주변 지역 변수의 값이나 참조를 사용하는 동작을 정의할 때

C++에서는 람다 표현식이 도입되기 전에도 함수 포인터나 함수 객체를 이용하여 호출할 동작을 다른 함수에 전달할 수 있었다. 람다 표현식을 사용하면 별도의 함수나 함수 객체 클래스를 직접 정의하지 않고도 이러한 동작을 간결하게 작성할 수 있다.

람다 표현식은 흔히 익명 함수라고도 부르지만, 정확하게는 **호출 가능한 함수 객체를 생성하는 표현식**이다.

### 2. 람다 표현식의 기본 구문

람다 표현식의 기본 형태는 다음과 같다.

```cpp
[캡처 목록](매개변수 목록) -> 반환형 {
    실행할 문장들
}
```

| 구성 요소 | 의미 |
|---|---|
| 캡처 목록 | 주변 지역 변수 등을 어떤 방식으로 사용할지 지정한다. |
| 매개변수 목록 | 람다를 호출할 때 전달받을 매개변수를 선언한다. |
| 반환형 | 람다 호출 결과의 자료형을 지정한다. 추론 가능한 경우 생략할 수 있다. |
| 본문 | 람다를 호출할 때 실행할 문장들을 작성한다. |

다음 람다 표현식은 두 정수를 받아 합을 반환한다.

```cpp
[](int x, int y) -> int {
    return x + y;
}
```

이 예에서는 반환형을 `int`로 추론할 수 있으므로 다음과 같이 생략할 수 있다.

```cpp
[](int x, int y) {
    return x + y;
}
```

매개변수가 없고 `mutable`, 예외 명세, 명시적 반환형 등을 사용하지 않는 기본 형태에서는 빈 괄호 `()`도 생략할 수 있다.

```cpp
[] {
    return 10;
}
```

람다 표현식을 평가하면 클로저 객체가 생성되지만, 이때 본문이 실행되는 것은 아니다. **생성된 클로저 객체를 호출할 때 본문이 실행된다.**

### 3. 람다를 변수에 저장하여 호출하기

람다 표현식으로 생성된 클로저 객체를 변수에 저장하면 여러 번 호출할 수 있다.

클로저 객체의 타입은 컴파일러가 정의하는 이름 없는 클래스 타입이므로, 일반적으로 `auto`를 사용하여 변수를 선언한다.

```cpp
#include <iostream>

int main() {
    auto sum = [](int x, int y) {
        return x + y;
    };

    std::cout << "sum: " << sum(3, 4) << '\n';
    std::cout << "sum: " << sum(10, 20) << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
sum: 7
sum: 30
```

`sum`은 클로저 객체를 나타내는 변수이다. `sum(3, 4)`는 해당 객체의 함수 호출 연산자 `operator()`를 호출한다.

위 코드는 변수 선언문이므로 람다 본문의 닫는 중괄호 뒤에 세미콜론 `;`을 붙여야 한다.

### 4. 클로저 타입과 클로저 객체

람다 표현식, 클로저 타입, 클로저 객체는 다음과 같이 구분한다.

| 용어 | 의미 |
|---|---|
| 람다 표현식 | 함수 객체를 생성하는 표현식 |
| 클로저 타입 | 컴파일러가 람다 표현식에 대해 정의하는 고유한 이름 없는 클래스 타입 |
| 클로저 객체 | 람다 표현식을 평가하여 생성한 해당 클로저 타입의 객체 |

서로 다른 람다 표현식은 본문이 같더라도 서로 다른 클로저 타입을 갖는다.

#### 4.1. 동작과 캡처 상태를 함께 다루는 객체

클로저 객체는 호출할 동작과 그 동작에서 사용할 캡처 상태를 함께 다룬다.

다음 예제에서 `[offset]`은 주변 지역 변수 `offset`의 값을 복사하여 캡처한다.

```cpp
#include <iostream>

int main() {
    int offset = 10;

    auto addOffset = [offset](int value) {
        return value + offset;
    };

    std::cout << addOffset(5) << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
15
```

각 구성 요소의 의미는 다음과 같다.

| 구성 요소 | 의미 |
|---|---|
| `[offset](int value) { return value + offset; }` | 람다 표현식 |
| `addOffset` | 생성된 클로저 객체를 나타내는 변수 |
| `[offset]` | 클로저 객체가 생성될 때 `offset`의 값을 복사하여 캡처 |
| `(int value)` | 호출할 때 전달받는 매개변수 |
| `addOffset(5)` | 클로저 객체를 호출하여 본문 실행 |

여기에서 `offset`은 클로저 객체를 생성할 때 캡처하고, `value`는 객체를 호출할 때 전달받는다.

#### 4.2. 직접 작성한 함수 객체와 비교하기

앞의 람다를 이해하기 위해 함수 객체 클래스를 직접 작성하면 다음과 비슷한 형태가 된다.

아래 코드는 개념 설명을 위한 것이다. 컴파일러가 실제로 생성하는 코드와 정확히 같다는 뜻은 아니다.

```cpp
#include <iostream>

class AddOffset {
private:
    int offset_;

public:
    explicit AddOffset(int offset)
        : offset_(offset) {}

    int operator()(int value) const {
        return value + offset_;
    }
};

int main() {
    int offset = 10;
    AddOffset addOffset(offset);

    std::cout << addOffset(5) << '\n';

    return 0;
}
```

이 클래스에서 다음과 같은 대응 관계를 확인할 수 있다.

* 멤버 변수 `offset_`은 값으로 캡처한 데이터를 보관하는 역할을 한다.
* 멤버 함수 `operator()`는 람다 본문에 해당하는 동작을 수행한다.
* `addOffset(5)`는 `addOffset.operator()(5)`를 호출하는 형태이다.

람다 표현식을 사용하면 이러한 함수 객체 클래스를 직접 작성하는 과정을 줄일 수 있다.

#### 4.3. 캡처가 없는 람다도 클로저 객체를 생성한다

다음 람다 표현식도 클로저 객체를 생성한다.

```cpp
auto sum = [](int x, int y) {
    return x + y;
};
```

캡처 목록이 비어 있으므로 주변 변수를 캡처하지 않는다. 하지만 두 매개변수를 더하는 동작을 수행하는 함수 객체는 생성된다.

따라서 **캡처 유무와 관계없이 람다 표현식을 평가한 결과는 클로저 객체**이다.

### 5. 다른 함수에 람다 전달하기

람다 표현식은 알고리즘에 비교 기준이나 처리 동작을 전달할 때 자주 사용한다.

다음 예제는 `std::sort()`에 내림차순 비교 동작을 전달한다.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {3, 1, 4, 2};

    std::sort(numbers.begin(), numbers.end(),
              [](int a, int b) {
                  return a > b;
              });

    for (int number : numbers) {
        std::cout << number << ' ';
    }
    std::cout << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
4 3 2 1
```

`std::sort()`는 전달받은 함수 객체를 호출하여 두 원소의 순서를 판단한다. 이 예제에서 비교 결과가 `true`이면 `a`가 `b`보다 앞에 와야 한다는 뜻이다.

비교 동작을 사용하는 위치에 직접 작성하므로 정렬 기준을 쉽게 확인할 수 있다.

### 6. 캡처 절

람다는 자신을 둘러싼 범위의 지역 변수나 매개변수를 **캡처(capture)**하여 사용할 수 있다.

캡처 방식에는 값을 복사하는 방식과 원래 변수를 참조하는 방식이 있다.

다음 표는 일반적인 지역 변수 캡처를 기준으로 설명한 것이다.

| 캡처 절 | 의미 |
|---|---|
| `[]` | 아무것도 캡처하지 않는다. |
| `[a]` | `a`를 값으로 캡처한다. |
| `[&a]` | `a`를 참조로 캡처한다. |
| `[a, &b]` | `a`는 값으로, `b`는 참조로 캡처한다. |
| `[=]` | 암시적 캡처가 필요한 변수를 기본적으로 값으로 캡처한다. |
| `[&]` | 암시적 캡처가 필요한 변수를 기본적으로 참조로 캡처한다. |
| `[=, &a]` | 기본적으로 값으로 캡처하되, `a`는 참조로 명시적으로 캡처한다. |
| `[&, a]` | 기본적으로 참조로 캡처하되, `a`는 값으로 명시적으로 캡처한다. |

`[=]`와 `[&]`는 주변의 모든 변수를 무조건 캡처한다는 뜻이 아니다. 람다 본문의 사용에 따라 캡처가 필요한 변수에 적용할 기본 방식을 지정한다.

#### 6.1. 값 캡처와 참조 캡처

값 캡처는 클로저 객체가 생성될 때 변수의 값을 복사한다. 참조 캡처는 원래 변수를 참조하므로 이후 원래 변수의 변경 사항을 반영한다.

```cpp
#include <iostream>

int main() {
    int number = 10;

    auto byValue = [number] {
        return number;
    };

    auto byReference = [&number] {
        return number;
    };

    number = 20;

    std::cout << "value: " << byValue() << '\n';
    std::cout << "reference: " << byReference() << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
value: 10
reference: 20
```

* `byValue`는 클로저 객체 생성 시 복사한 값 `10`을 사용한다.
* `byReference`는 원래 변수 `number`의 현재 값 `20`을 사용한다.

참조로 캡처한 변수를 통해 원래 변수의 값을 변경할 수도 있다. 단, 원래 변수가 수정 가능한 변수여야 한다.

```cpp
int count = 0;

auto increment = [&count] {
    ++count;
};

increment();  // 원래 변수 count는 1
```

참조 캡처는 원래 변수의 수명을 연장하지 않는다. 람다가 해당 변수를 사용할 때는 그 변수가 여전히 존재해야 한다. 특히 람다를 함수에서 반환하거나 나중에 실행하도록 저장할 때 주의해야 한다.

#### 6.2. 값으로 캡처한 복사본 변경하기

일반적인 람다에서는 함수 호출 연산자 `operator()`가 기본적으로 `const` 멤버 함수이므로, 값으로 캡처한 일반 변수의 복사본을 직접 변경할 수 없다.

`mutable`을 지정하면 이러한 `const` 제약이 제거되어 수정 가능한 복사본을 변경할 수 있다.

```cpp
#include <iostream>

int main() {
    int count = 0;

    auto increment = [count]() mutable {
        return ++count;
    };

    std::cout << increment() << '\n';
    std::cout << increment() << '\n';
    std::cout << "original: " << count << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
1
2
original: 0
```

같은 클로저 객체를 호출하므로 변경된 복사본의 값은 다음 호출에도 유지된다. 원래 변수 `count`의 값은 변경되지 않는다.

#### 6.3. 캡처 없이 접근할 수 있는 변수

빈 캡처 절 `[]`는 아무것도 캡처하지 않는다는 뜻이다. 외부에 선언된 모든 변수에 접근할 수 없다는 뜻은 아니다.

이름이 보이는 전역 변수나 정적 지역 변수는 캡처 없이 사용할 수 있다.

```cpp
#include <iostream>

int globalValue = 10;

int main() {
    static int staticValue = 20;

    auto sum = [] {
        return globalValue + staticValue;
    };

    std::cout << sum() << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
30
```

### 7. 초기화 캡처 — C++14부터 지원

C++14부터는 캡처 절에서 새로운 변수를 도입하고 초기화할 수 있다. 이를 **초기화 캡처(init-capture)**라고 한다.

```cpp
#include <iostream>

int main() {
    int number = 10;

    auto calculate = [value = number * 2] {
        return value + 1;
    };

    std::cout << calculate() << '\n';

    return 0;
}
```

실행 결과는 다음과 같다.

```text
21
```

`value`는 바깥에서 미리 선언한 변수가 아니다. 캡처 절에서 새로 도입한 이름이며, 클로저 객체를 생성할 때 `number * 2`의 값으로 초기화된다.

이 예제는 초기화 식을 계산할 때 `number`를 사용하고, 계산 결과를 클로저 객체에 저장한다. `number` 자체를 캡처하는 것은 아니므로 이후 `number`가 변경되어도 저장된 `value`에는 영향을 주지 않는다.

초기화 캡처의 자료형은 초기화 식에 `auto` 방식의 자료형 추론을 적용하여 결정한다.

```cpp
auto first = [value = 10] {
    return value;  // value는 int
};

auto second = [value = 3.5] {
    return value;  // value는 double
};
```

초기화 캡처 예제를 컴파일하려면 C++14 이상의 언어 모드를 사용해야 한다.
